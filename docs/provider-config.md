# 中转站配置

BalanceHub 当前支持 NewAPI、Sub2API 和通用 API Key。AnyRouter 这类站点按 NewAPI 接口方言处理，不在界面上作为独立中转站类型展示。除中转站外，OAuth 授权账号和 CPA 网关也在同一个编辑窗口里配置；窗口标题、地址字段和保存按钮按当前选中的协议写作「中转站」「账号」或「网关」。

中转站配置和凭据只保存在当前电脑的应用数据目录中。导出配置会包含中转站信息和凭据，请只在可信设备之间迁移。

编辑窗口左侧是分区导航，右侧同一时间只展开一个分区：基础信息、认证凭据、额度接口、模型、请求配置、自动任务、网络与通知。导航项按当前协议的能力增减，并显示草稿里的当前取值。基础信息先展示接入类型、地址和备注，站点识别结果直接显示在地址下方；每种接入类型在选型卡里带一句说明。选择通用 API Key 时，地址下方还会列出常见 OpenAI 兼容网关，点选后填入地址和名称。认证输入和配置助手在认证凭据分区，签到只对支持账号签到的协议出现。测试连接与保存按钮固定在底部。

保存成功后窗口关闭，额度与模型信息继续在后台刷新。保存失败时，原因显示在底部，填写内容保留，可以修改后重试；保存期间仍可关闭窗口。遇到响应超时，请先核对卡片是否已更新，再决定是否重试。

选择 **跟随全局** 时，刷新间隔、签到时间、自动测活、代理和通知旁会显示对应的全局配置。全局自动刷新、签到或通知关闭时，会保留关闭提示，单独填写间隔、时间或渠道不会打开全局开关。通知渠道列表标明已停用的渠道；这些提示反映保存的配置，实际执行与发送结果仍以任务记录为准。

自定义测活参数按执行 Agent、模型、周期和超时集中排列。测活模型可以从已获取的模型中搜索选择，也可以直接输入；留空时显示所跟随的全局模型。话术策略和按 Agent 指定的地址收在“更多测活设置”里，日常只调周期与超时。

## 认证方式

NewAPI / Sub2API 新配置默认使用账号密码。账号密码可以登录站点，并按需补全后续会话、访问令牌和 API Key；已有凭据时也可以按协议直接选择 Cookie、访问令牌或 API Key。通用 API 只使用 API Key。

各类认证凭据直接展开，可同时查看和填写。在区块右侧选择 **用于连接**，当前认证方式会标为 **当前使用**；切换时输入区保持展开，已填写内容保留。必填标记按当前认证方式显示，多个认证方式共用的用户 ID 只填写一次。已保存中转站的 API Key 使用下方的管理区；只有一种认证方式时不显示选择控件。

点击 **保存中转站** 时，会检查当前认证方式后续需要的凭据，并自动补全缺项：账号密码可建立登录会话或获取访问令牌，再同步站点已有 API Key。凭据齐全、使用纯 API Key，或已有可续期会话且不需要额外访问令牌时，会跳过相应补全。**自动完成配置** 仍可用于提前执行这套流程。

只有一把可读取的 Key 时自动选中；已有当前调用 Key 时保留原选择；多把 Key 则弹出选择窗口，选定后继续保存。确实没有站点 Key 时会打开创建表单，新账号会先保存，再创建和管理 Key，取消创建仍保留账号配置。生成会使旧访问令牌失效的新令牌时，需要确认影响。补全失败或超时会显示原因并保留填写内容；补全过程中可以关闭窗口，迟到的结果不会改写重新打开的草稿。

### 协议边界

- NewAPI：支持账号密码、登录会话（手动 Cookie 或浏览器登录导入）、访问令牌和 API Key，并按站点能力提供签到、日志、用量、密钥管理等功能。
- Sub2API：支持账号密码、Access / Refresh Token 和网关 API Key，并提供用户资料、额度、用量、日志、卡密兑换和密钥管理能力。
- 通用 API Key：通过 OpenAI 兼容 `/v1/models` 接口验证和同步模型；连接测试还会用模型发起一次最小对话请求，不提供账号、签到或站点密钥管理能力。

账号操作入口在卡片的站点能力菜单：NewAPI 可以修改用户名和显示名，NewAPI 与 Sub2API 都可以使用兑换码补充余额。兑换成功后应用会刷新余额和订阅窗口；后续刷新失败只会保留旧余额，不会把已经成功的兑换回滚成失败。

### 模型列表

中转站卡片统一以“可用模型”展示模型列表、数量和同步状态。NewAPI 优先使用当前调用 Key 请求网关模型接口，结果按该 Key 的分组和模型限制生成；账号登录是否成功不会阻塞可用 Key 的模型读取。没有完整 Key，或 Key 模型接口请求失败时，使用账号认证的中转站会回退到账号模型接口。模型详情和能力检测中保留实际读取结果及失败原因。账号模型是多个可用分组的汇总，不能直接视为当前 Key 的调用权限。

NewAPI 的纯 API Key 认证、Sub2API 和通用 API Key 仅使用网关模型接口。Key 接口成功返回空列表时不回退；所有可用来源均失败时保留上次结果并显示错误。模型列表独立记录同步时间，切换当前 Key 或修改其分组、模型及访问限制后会清除旧模型缓存，下次查看时重新获取。

### 账号密码

在同一中转站协议内切换认证方式，会保留已填写的 Cookie、访问令牌、账号密码和 API Key，以及后端维护的续期会话；保存后重新打开也可继续切换。实际修改登录账号、密码或站点地址时，应用会重新判断原登录会话是否还能使用。

账号密码适合首次配置或希望由应用建立会话的场景。应用只在登录站点时使用账号密码，登录成功后缓存 Session，并可继续补全访问令牌和 API Key。

### 登录会话（Cookie / OAuth）

Cookie 适合完整账号能力，包括读取账号信息、额度、签到、API Key 管理、请求日志等。

使用 Cookie 时，用户 ID 可以由应用自动解析，通常不需要手动填写。

NewAPI 站点也可以在编辑窗口中选择“登录并导入”。选择已有登录账号，或通过“使用新账号”创建独立登录环境，然后在小窗中使用站点提供的 Linux DO、GitHub 等方式登录。完成后自动核对站点账号、保存会话并刷新账号信息。为已有卡片重新登录时，如果返回的站点账号与原卡片不同，应用会拒绝覆盖；同一站点的其他账号应使用另一张卡片。

账号选择窗口会显示真实平台身份、本地备注及此站点上次使用的账号。新增账号后直接继续当前站点登录。可以关闭编辑窗口，随后从顶部后台任务中查看进度、显示原登录窗口或取消等待；完成后可以直接进入账号或站点凭据详情。

登录账号管理可以从中转站编辑窗口，或“设置 → 登录与授权 → 登录账号与授权”进入。每个账号分别保存浏览器环境；清除本地登录只清理 Cookie 和浏览器存储，身份、历史记录及站点关联保留，之后需要重新登录同一身份。删除本地账号会解除关联，但保留已导入的站点凭据。平台端的授权通过“平台授权管理”打开对应平台页面管理。

浏览器组件仍为可选功能，在登录账号管理中点击“浏览器组件”即可管理。使用运行环境检测到的兼容浏览器时只下载运行组件；选择独立模式时还会下载 Chromium。普通账号密码和 API Key 接口请求无需安装。两种浏览器模式都使用独立账号目录，但登录和授权仍发生在真实站点，平台端的授权记录及旧会话有效性由站点自身策略决定。

站点 Cookie、JWT、续期 Cookie、访问令牌和 API Key 在“凭据详情”中查看，平台 Cookie 在“登录账号管理”中查看，敏感值默认隐藏。站点 JWT 属于站点会话。凭据验证只覆盖界面说明的当前请求范围，不代表其他已保存凭据或平台登录状态同时通过验证。

### 访问令牌

访问令牌适合不想长期使用 Cookie 的场景。使用访问令牌时，用户 ID 需要明确填写或由同步流程补齐。

如果当前中转站支持令牌创建，但本地配置里缺少令牌，应用会在需要同步时提示是否创建，不会静默创建。

### API Key

API Key 只适合 Key 维度的额度查询和相关操作，不等同于账号登录态。

使用账号凭据补全配置时，应用会先读取并保存站点已有的 API Key（最多 100 个）。存在多个 Key 时，需要选择用于模型请求及未单独指定场景的“当前调用 Key”；只有确认列表为空时才提示创建。纯 API Key 认证只维护本地 Key，不提供站点同步或创建功能。

入口：**编辑中转站 → 认证凭据 → API Key**。点击 **创建站点 Key**，或在已有 Key 旁点击 **编辑设置**；首次配置中转站时也使用同一套创建表单。

| 设置 | NewAPI | Sub2API |
| --- | --- | --- |
| 分组 | 从账号可用分组中选择，可跟随账号分组 | 从账号可绑定分组中选择；已绑定的 Key 可切换到其他分组 |
| 额度 | 无限额度，或设置剩余额度；按站点显示单位换算 | 无限额度，或设置总额度（USD）；保留已用额度 |
| 有效期 | 永不过期，或指定到期时间 | 创建时按天设置；编辑时可指定时间或取消到期 |
| IP 限制 | 白名单，支持 IPv4、IPv6、CIDR | 白名单和黑名单，支持 IPv4、IPv6、CIDR |
| 模型限制 | 指定模型白名单，模型候选项来自账号接口 | 由分组决定，不提供 Key 级模型白名单 |
| 自动分组 | auto 分组可跨组重试；站点提供接口时可选择自动分组范围 | 不提供 |
| 周期消费上限 | 不提供 | 分别设置 5 小时、1 天、7 天的 USD 上限，0 为不限 |
| 自定义密钥值 | 由站点生成 | 创建时可选；已创建 Key 的值不可更改 |
| 启用与停用 | 支持 | 支持 |

表单只显示当前协议支持的选项。常用设置直接展示，IP、模型和周期限制按需展开。远程设置立即生效；本地备注独立保存，不会修改站点名称。NewAPI 编辑会先读取最新配置，保留没有改动的额度、有效期和限制；Sub2API 只提交改动字段。编辑和删除成功后直接更新对应 Key。NewAPI 创建接口没有返回 ID 时，会对比创建前后的 Key 元数据来确认新 Key，避免误认同名资源；只读取新 Key 的完整值，不逐把重新读取整个密钥库。请求超时或站点已保存但读取失败时，应先同步确认，避免重复创建。

API Key 列表还支持添加已有 Key、复制、删除和切换当前调用 Key。没有站点管理凭据时，曾同步的 Key 仍可仅从当前卡片移除，站点令牌不会因此撤销。每个 Agent CLI 的默认配置可独立绑定其中一把 Key；被 Agent 使用的 Key 需要先切换绑定才能删除。Key 管理操作与编辑器底部的“保存中转站”分别保存，后者只负责其余配置草稿。

使用 API Key 时要注意：

- 不支持签到。
- 不代表账号总额度。
- 某些中转站返回的 Key 额度上限可能是无限。

## 自定义请求与余额接口

“请求配置 → 请求约定”可以为中转站补充额外请求头，并按协议选择 API Key 的发送方式。额外请求头附加到该站点的每个协议级请求（模型列表、额度、日志等），名称或值为空的行会被忽略；OAuth 账号与 CPA 网关直接使用各自的客户端，不显示这一项。通用 API Key 还可以把发送方式改为 `X-Api-Key`，或选择不自动附加凭据、完全由自定义请求头提供认证。发送方式只影响模型列表、余额接口这类查询，不改变中转站在其他功能中的认证方式。

通用 API Key 没有内置额度接口时，可以在“额度接口”分区声明余额来源：

- **接口地址**：支持绝对地址，也支持以中转站地址为基准的相对路径。
- **请求方式与访问令牌**：`GET` 或 `POST`；访问令牌留空时使用当前 API Key。自定义请求头同样会附加到这个请求。
- **表达式**：用 JSON 路径读取余额和总额，例如 `data.balance`、`data.plan.reset_at`；支持通配（`data.items.*.used`）、条件（`data.keys[status=active].used`）、聚合（`sum` / `max` / `min` / `count`）和算术（`(data.total - data.balance) / data.total * 100`）。余额与总额一起用来计算已用比例。
- **换算与货币符号**：表达式数值除以换算单位后作为展示金额，`0` 表示不换算；货币符号留空时跟随卡片默认值。
- **订阅窗口**：最多声明 3 个窗口（名称、已用、上限、重置时间表达式），结果直接进入卡片和中转站详情里的窗口条；至少填写已用或上限之一。

表达式在读取余额时求值。分区标题旁的“读取一次”会直接发起一次连接测试，并把余额这一步的结果贴在表达式上方；改动任意字段后旧结果会清空，避免把上一版表达式的结论当成当前配置。全部已声明的表达式都取不到值时，本次额度读取失败并给出具体名称；只有部分表达式失败时保留已经取到的值（例如余额缺失时，窗口仍然照常展示），失败的表达式不会出现在结果里。读取失败只影响额度区块，模型列表和其他功能照常刷新。余额表达式取到负数（常见的不限量占位值）时按不限量展示。

### 接口目录

“请求配置 → 接口目录”按账号与登录、签到、公告、API Key 管理、用量与额度、模型和外部链接分组，列出 BalanceHub 对这个协议会发出的每个请求：方法、默认路径、固定查询参数、适配器自动写入的请求头、认证方式和路径占位符。目录与后端实际请求使用同一份协议定义，界面不另写一份；默认值只读，方便先看清应用请求了什么。

每个接口都可以单独改写，未填写的部分继续沿用默认值：

- **路径**：只填站点地址后的部分，必须以 `/` 开头，可以保留 `{id}` 这类占位符；查询参数不要写进路径。
- **查询参数**：按名称合并到默认参数，同名覆盖；值留空表示删除这个默认参数。新增的参数追加到末尾。
- **请求头**：只附加到这个接口，同名时覆盖该接口原有的请求头，包括卡片级请求头和适配器自动写入的值。
- **邀请链接**：把“邀请链接”的模板改成站点实际的注册页，例如 `/register?aff={code}`、`/signup?invite={code}` 或 `/regist?code={code}`；`{code}` 必须保留，复制链接时会替换成当前邀请码。修改模板会让已缓存的邀请链接失效，下次复制时重新向站点读取邀请码。

改写保存后从下一次请求开始生效，只作用于当前卡片。接口调用失败时，先对照接口目录确认默认路径和参数是否与站点一致，再检查改写；读取错误会带上失败的接口名称，以及实际发出的请求方法和路径（含改写后的结果）。请求体字段仍由对应操作写入，目前不提供逐字段改写。通用 API Key 没有内置请求目录，继续使用额外请求头和余额接口声明的 URL、参数与表达式。

## 模型展示与覆盖

“模型 → 模型展示”决定卡片、模型列表和 Agent 模型选择器里出现哪些模型，以及每个模型的元数据从哪里来。

**只展示 / 隐藏匹配的模型** 接受 glob（如 `claude-*`）和 `re:` 正则（如 `re:^gpt-5`），不区分大小写；也可以点“从站点模型选择”，从该站点已同步的模型列表里勾选精确模型 ID，再点一次取消。通配符和 `re:` 正则仍需直接输入。隐藏列表优先于展示列表；两者都为空时展示站点返回的全部模型。规则只影响展示，原始模型列表仍完整保存在卡片能力数据里，详情中可以查看被隐藏的数量。

**模型列表地址** 只对通用 OpenAI 兼容 API Key 生效，留空时使用协议默认的 `/v1/models`。**models.dev 供应商** 用于借用目录里的上下文、价格等资料补全缺失字段；留空时按模型 ID 自动匹配。

**模型覆盖** 按模型 ID 逐项添加，覆盖优先于 models.dev，未填写的字段仍由目录补全：

- **显示名称**：在模型元数据中展示的名称；留空使用模型 ID。
- **实际上游模型 ID**：发给上游的模型名；留空与模型 ID 相同。界面、模型列表和请求历史仍显示用户看到的模型 ID，只有实际请求会换成上游名称。
- **用量归并到**：用量排行按这个模型 ID 归并，适合同款模型的多个上游 ID 合并计数。
- **上下文窗口 / 输出上限**：tokens；留空时使用 models.dev 或站点返回的值。
- **价格**：输入、输出、缓存读取、缓存写入四项，单位是 USD / 百万 tokens。
- **推理档位**：该模型接受的档位名称（如 `low` / `high`），供 Agent 配置表单与 CLI 原生档位取交集；留空表示不额外声明。
- **推理参数**：未声明、发送、不发送三态。选择“不发送推理参数”时，Agent 配置表单会锁定该模型的推理字段。
- **从模型选择器隐藏**：等价于把该模型加入隐藏列表，但保留覆盖中的其他元数据。

## 自动刷新与失败退避

自动刷新按站点记录连续失败次数，并按失败来源决定下一次尝试时间，而不是固定等待 60 秒：

- **凭据被拒绝**：自动刷新暂停 6 小时，避免持续拿错误凭据请求站点；修改凭据后可以手动刷新立即重试。
- **站点限流**：按响应中的 `Retry-After` 等待，范围限制在 60 秒到 30 分钟；没有该响应头时从 5 分钟起。
- **网络、超时、5xx 等瞬时失败**：在“失败后重试”次数内按 1、2、4 分钟递增，单次上限 15 分钟；额度用完后回到正常刷新间隔。

冷却只限制自动刷新，手动刷新不受影响；成功一次即清除冷却和连续失败次数。冷却期间卡片在同步说明下方写明“冷却中 · N 分钟后重试”，悬停可以看到具体原因。

## 备用地址

备用地址是同一个站点的其他域名，填在“请求配置 → 备用地址”，保存后用于主地址临时不可用时接管请求。请求按填写顺序尝试：主地址连接失败、过盾没有通过或返回 5xx（需要过盾的拦截页除外）时改用下一个地址重发；4xx 这类业务响应仍按原地址的结果处理，不触发切换。只有发往中转站地址本身的请求参与回退，公告原文链接、下载地址等其他来源的请求不受影响。

切换后 10 分钟内，新操作直接从备用地址开始；到期会重新先试主地址，主地址恢复后自动回到主地址。切换发生在请求层，`Origin` / `Referer` 等由地址拼出的请求头随地址一起改写。卡片在同步说明下方写明当前使用的是第几个备用地址与主机名，悬停可看完整地址与切换时间；主地址正常时这一行不出现。

备用地址只对经过中转站传输层的协议生效。CPA 网关与 OAuth 账号的请求直接发往各自的管理接口或厂商接口，编辑窗口不为它们显示这一项。每个中转站最多保存 16 条，留空的行会被忽略，重复地址只保留一次。

## 连接测试

测试连接会尽量完成这些检查：

- 中转站地址是否可访问。
- 站点信息是否可以读取。
- 当前认证方式是否有效。
- 账号或 API Key 额度接口是否可用。
- 通用 API Key 会使用测活模型，或模型列表里的第一个对话模型，发起一次最小真实调用；只有 embedding、语音、图片等模型时跳过这一步。真实调用失败会让整次连接测试失败，因为 `/v1/models` 能返回列表并不代表这把 Key 现在还能生成内容。

测试结果和具体步骤保留在编辑窗口底部；修改配置后，旧测试结果会清除。已有中转站的配置仍与本次测试一致时，后端会更新测试读取到的额度。新建或修改后保存的中转站会在后台重新刷新额度，保存动作不会再次发起完整连接测试。
