# Agent 管理改进与验收

本轮参考 [Magpie](https://github.com/yetone/magpie/tree/657e48ab) 的实现思路，扩展 BalanceHub 已有的资产库、配置事务、会话索引和任务界面。以下七项已接入代码；配置功能的实际使用效果由用户在隔离开发版验收。

## 实施范围

| 方向 | 操作入口 | 已接入的改进 |
| --- | --- | --- |
| 读取与扫描 | Agent 总览、资产和配置来源 | 一次扫描内复用路径观察、文本读取与解析结果，写入前重新校验 |
| 共享指令 | Agent → 指令 | 多套公共正文与 Agent 补充，配置预览、Diff、管理区块移除和 WebDAV 同步 |
| MCP 诊断 | MCP 详情 → 连接状态 → 检测连接 | stdio / Streamable HTTP / SSE 检查、阶段状态、取消和工具搜索 |
| WSL | Agent → 环境；历史会话的环境筛选 | 发行版检测、按需启动、配置文件、会话检索与原生继续 |
| 模型资料 | 中转站可用模型窗口、临时 CLI 模型选择 | 上下文、输出上限、能力、模态和公开价格资料 |
| 原生会话用量 | 历史会话 → 详情 → 用量 | 从原生日志增量提取用量，合并重复记录，按已知模型资料估算费用 |
| 配置读写 | 原生配置和资产定义编辑器 | 保留 BOM、行尾和原生格式，补全文件身份、硬链接及权限校验 |

本地协议网关与多账号路由需要独立的产品与运行时设计，不在这份 Agent 管理改进中混入。

## 行为与边界

### 读取与扫描

- 复用已有索引和缓存，在单次同步读取范围内减少相同文件的重复读取与解析；外层读取结束后释放临时缓存。
- 路径观察最多 16,384 项，解析缓存预算 8 MiB，避免扫描过程持续占用内存。
- 文件指纹和写入前检查使用新的观察结果；权限、授权和文件句柄不作为扫描缓存复用。
- 本轮没有执行大规模性能基准，不提供未经测量的提速百分比。

### 共享指令

- 在“指令”页新建方案，分别编辑公共正文和各 Agent 补充。方案保存在共享库，可随 WebDAV 同步。
- 点击“配置到 Agent”，选择环境、Agent 和原生指令文件，再进入既有配置预览与 Diff 流程。
- 写入使用管理区块，保留原文件区块外的正文。发现原生内容已变化时要求合并；损坏或重复的管理标记不会直接覆盖。
- Codex 已存在 `AGENTS.override.md` 时优先使用它；创建默认指令文件使用 `AGENTS.md`。
- “移除共享区块”只移除目标文件中的受管内容。删除共享方案会保留已写入 Agent 的指令。
- 编辑器可关闭并保留草稿；保存结果通过 revision 校验，旧请求不会关闭新草稿或覆盖更新后的列表。

### MCP 连接诊断

- 仅在点击“检测连接”后连接远程服务或启动本地 MCP，执行初始化、协议协商和工具列表读取，不调用具体工具。
- 支持 stdio、Streamable HTTP 和旧 SSE；协商版本涵盖 `2024-11-05`、`2025-03-26`、`2025-06-18`、`2025-11-25`。
- 前端展示阶段、耗时和结果，支持取消。后台任务限制总时长和并发数，并负责本地进程、HTTP 会话的结束清理。
- 工具列表展开后才渲染，每页 50 项，搜索和重新检测重置页码；协议读取上限为 5,000 个工具。
- 复用 App 的代理解析。支持配置中的环境变量引用；不执行 `headersHelper`，不复用 Agent 私有 OAuth 会话。需要这些认证方式或使用 WebSocket 的连接会说明需要回到原生 Agent 检查。

### WSL 环境

- Windows 的“检测环境”仅探测正在运行的发行版。已停止的发行版保留已有结果，点击“启动并检测”才启动指定发行版。
- 本机与各发行版使用独立的配置来源身份和授权代次。配置编辑、Diff 和写入复用既有配置事务。
- 支持 Linux 路径与 `\\wsl.localhost\…` / `\\wsl$\…` 的映射，保留 Linux 路径大小写；文件访问、写入和继续会话前复查发行版状态。
- 历史会话可按环境筛选。WSL 来源后台更新后通知会话列表和统计，不因切换页签重新扫描所有来源。
- 继续 WSL 会话沿用发行版内的 Agent 配置；本轮尚未接入 WSL 临时中转站切换，也不将 Linux CLI 记为 Windows 的首选安装。
- macOS / Linux 页面说明 WSL 仅在 Windows 提供。Windows 交叉编译已通过，WSL 启停、UNC 读写和终端继续仍需 Windows 实机验收。

### 模型资料

- 资料来自 models.dev，缓存 24 小时；并发刷新请求合并，失败后退避，避免多个窗口重复下载。
- 资料只补充模型说明。当前 API Key 的可用模型仍由中转站返回，资料缺失不阻止选择已有模型。
- 同名模型存在歧义时不随意套用某个供应商的资料。公开价格仅用于参考，实际能力与费用以中转站为准。

### 原生会话用量

- Claude、Codex、Gemini 和 Grok 的用量随既有会话索引增量读取，不为展示用量另做一次全量扫描。
- Claude 按消息与请求标识去重；Codex 支持累计值及 `thread_token_usage` 记录；Gemini 的消息更新和回退同步清理对应用量；Grok 读取原生 turn / modelUsage。
- 缺失字段显示未知，计数回退、索引未完整和无法可靠归属模型的记录保留不完整状态。累计计数发生模型切换时不全部归到最后一个模型。
- 展开“用量”后才读取参考价。只能定价部分记录时显示“已知部分参考估算”，无价格资料不按零费用处理。
- 本轮没有宣称覆盖所有原生日志变体或精确逐次请求计费；展示的是日志可确认的用量与公开价估算。

### 配置文件读写

- UTF-8 BOM 不进入编辑正文，保存时恢复；统一 CRLF 的文件保持 CRLF，混合行尾不强制统一。
- JSON / JSONC / TOML / dotenv、原生配置及相关资产编辑共用文本与布局处理，保留原有注释和编辑范围外的内容。
- 通过已验证的文件句柄识别硬链接；会拆开链接关系的原子替换会拒绝执行。
- Unix 保存文件所有者、组和模式；无法保持所有者时明确失败。Windows 保留 reparse 校验与 `ReplaceFileW`，文件身份接口回退后仍拒绝无效的全零身份。
- 本轮没有增加跨平台完整 ACL / 扩展属性保留协议。

## 验证约束

- 按仓库 `AGENTS.md`，Agent 配置由用户验收；本轮不新增或运行其自动测试，不写合成配置，不执行桌面自动验收。
- 构建与静态检查使用仓库共用 target，同一时间只运行一个重型 Cargo 任务。
- 开发版使用独立应用标识和配置目录；安装版不参与源码验证。
- Windows / WSL 运行行为需要实机确认，静态检查不能替代实机验收。
