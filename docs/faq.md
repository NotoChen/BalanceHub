# 常见问题

## `.sig` 文件是什么？

`.sig` 是应用内自动更新使用的签名文件，不是安装包。手动下载安装时不需要打开它。

## 应用内自动更新会怎么执行？

应用启动 30 秒后会静默检查一次，之后每 6 小时检查一次。检测到新版本时只展示提示，不会自动下载；用户确认安装后，应用才会下载当前平台匹配的更新包、校验 `.sig` 签名、安装并重启。

下载阶段可以取消；进入签名校验或系统安装阶段后不再允许取消。下载连续 45 秒没有进度、总时长超过 20 分钟或更新包超过 256 MiB 时会自动停止，用户可以稍后重试。

## 可以部署到 Docker 或自己的服务器上吗？

可以。`balancehub-server` 是无界面后端，托管与桌面版相同的前端页面，用浏览器访问；额度刷新、签到、测活、云端同步与 Agent 工作台都在服务器上执行，不要求服务器有桌面环境。发布页提供 Linux x64 / ARM64 的服务端 `tar.gz`，仓库根目录也提供 `Dockerfile` 与 `compose.yaml`。

服务器上装了对应 Agent CLI 时，Agent 工作台、配置读写和会话检索同样可用；终端启动和可见登录窗口需要服务器本身有桌面会话，没有时界面隐藏这些入口。服务端没有内置登录鉴权，请绑定回环地址或放在带认证的反向代理之后。完整步骤见[服务端部署](server-deployment.html)。

## 为什么 macOS 或 Windows 提示未知开发者？

安装包通过 GitHub Releases 分发。若系统尚未建立对当前发布者的信任，macOS 和 Windows 可能会提示未知开发者或 SmartScreen 拦截。

这是系统信任提示，不代表安装包一定损坏。请只从本仓库 Releases 下载；macOS 可在「系统设置 → 隐私与安全性」中选择「仍要打开」。

## 为什么签到记录为空？

部分中转站不提供官方签到记录接口。BalanceHub 会优先读取官方记录；如果远端不支持，则使用本地记录兜底。本地记录只能覆盖应用内执行过的签到。

## 为什么 API Key 查到的是无限额度？

部分中转站的 API Key 额度上限可能没有限制，接口会返回无限或无法计算的上限。BalanceHub 会按无限额度展示。
