# 快速开始

BalanceHub 是本地桌面应用。配置和中转站凭据保存在当前电脑的应用数据目录中，换电脑使用时可以通过导入导出迁移，也可以连接自己的 WebDAV 服务进行加密同步。

本文的 Agent 工作台入口对应当前仓库源码；已发布安装包的功能以 [更新记录](https://github.com/NotoChen/BalanceHub/blob/main/CHANGELOG.md) 为准。

## 1. 安装应用

打开 [GitHub Releases](https://github.com/NotoChen/BalanceHub/releases/latest)，下载当前系统对应的安装包。

- macOS：下载 `.dmg`。
- Windows：下载 `setup.exe`。
- Linux：按发行版选择 AppImage、deb 或 rpm。

Release 里的 `.sig` 文件是应用内自动更新使用的签名文件，不是手动安装入口。

## 2. 添加第一个中转站

首次启动后，按初始化引导添加中转站。

基础配置顺序是：

1. 中转站类型：选择 NewAPI、Sub2API 或通用 API Key。
2. 中转站地址：填写站点后台或 OpenAI 兼容 API 地址，核对下方的站点识别结果。
3. 认证方式：NewAPI / Sub2API 优先账号密码，也可以按协议使用 Cookie、访问令牌或 API Key；通用 API 只使用 API Key。

填写认证信息后，可以测试连接并查看检查步骤。保存成功后返回卡片，额度在后台刷新。

## 3. 日常使用

主面板顶部提供 **中转站 / Agent** 切换。中转站视角处理账号、额度和请求；Agent 视角处理本机工具、共享配置和运行实例。

- 点击刷新，更新所有中转站额度和账号状态。
- 点击签到，对支持签到的中转站执行签到。
- 在中转站卡片的快捷操作中，可以查看 API Key、用量趋势、请求日志、签到记录和测活记录。
- 在中转站卡片的快捷操作中，可以临时启动 Codex CLI、Claude Code、Gemini CLI 或 Grok Build，也可以把兼容配置添加到 CC Switch。
- 在设置里配置代理、通知、自动刷新、自动签到和测活参数。

应用设置中的更改会自动保存，保存进度或失败提示位于窗口标题旁。失败时草稿保留，可点击 **重试保存**；关闭窗口不会丢弃尚未保存的修改。同一次 App 运行期间再次打开设置，会保留上次查看的分类。

- **常规**：外观、启动行为和版本更新。
- **自动化**：自动刷新、签到、测活及测活提示词；时间间隔支持秒、分钟和小时。
- **终端与会话**：终端选择与会话索引。
- **通知**：渠道名称、类型、启停和测试结果。
- **网络与数据**：WebDAV 同步、代理、登录账号和配置备份。

关闭自动通知后仍可编辑渠道并手动测试。至少启用一个渠道即可发送测试，结果按渠道展示；移除渠道时会再次确认。

请求日志支持按模型名称筛选、清除筛选和翻页；点击记录查看详情，可以复制请求 ID、日志内容和原始 JSON。用量趋势可展开全部时段明细，小额消耗保留到小数点后六位。可用模型按名称排序并分页展示，搜索后的 **复制筛选结果** 会复制全部匹配项；标题标明是账号还是 Key 的模型范围，读取失败时保留上次列表并显示原因。

顶部后台任务入口保留最近完成的记录，关闭面板不会清空；可主动点击 **清空记录**。站点公告在后台读取时不会自动标记已读，打开公告面板后优先显示未读内容。

## 4. 使用 Agent 工作台

切换到 **Agent** 后，总览卡片展示各 Agent 的原生图标、名称、版本和资源数量。点击版本号进入 **版本与路径**，查看本机安装或预览原渠道升级；确认升级后转入后台任务。未安装的 Agent 点击 **安装说明** 查看官方指南，自行安装后回到 App 刷新。

Skill、MCP、插件和 Hook 分类统一展示资产及各 Agent 的绑定，也可以从卡片按 Agent 筛选。用户已有的资源同样可以管理，并按来源区分独立配置、插件提供和 Agent 自带。共享定义保存到本地库后，还需选择 **应用到 Agent**、预览变更并确认，才会写入所选原生配置。Hook 页面提供通用规则管理；原生配置直接点击卡片上的文件名进入。

具体步骤与能力边界见 [Agent 工作台](agent-workbench.html)。

## 5. 迁移配置

多设备持续使用时，可在 **设置 → 网络与数据 → WebDAV 同步** 配置自己的服务，核对首次 diff 后按增量同步。连接步骤、同步范围和冲突处理见 [WebDAV 配置同步](webdav-sync.html)。WebDAV 连接表单需要主动保存。

在 **设置 → 网络与数据 → 数据备份** 中选择 **导出备份** 或 **选择备份**。导出的配置包含中转站、认证凭据和本地应用设置，适合在自己的电脑之间迁移。

恢复前会确认替换范围，并等待当前应用设置保存完成；恢复会完整替换当前配置，需要保留现有内容时请先导出。响应超时时先核对列表和设置，再决定是否重试。本地配置暂时读取失败时，也可以在主面板点击 **重新读取**。
