# Agent 自动更新

在 **Agent → 点击版本号 → 版本与路径** 中，可为每个已识别的安装开启自动更新。默认关闭，设置仅保存在本机，不随 WebDAV 同步到其他电脑。

- 每 6 小时检查原安装渠道的最新版本，与手动检测共享缓存；应用留在托盘时也会继续检查。
- npm 使用原 Node、npm 和全局安装目录；Homebrew 只升级对应 Formula 或 Cask；已支持的 Claude / Grok 原生安装使用自身更新命令。不会切换安装渠道或主动降级。
- 开始前检查正在使用此安装的进程、临时 CLI、测活和其他升级任务。有占用时等待，不关闭用户会话。等待期间可以关闭设置面板。
- 任务中心显示执行阶段、真实命令、输出、错误和升级后检测到的版本。安装命令开始前可以取消；开始后等待命令结束或超时，再核对结果。
- 失败、结果不确定或版本没有提升时暂停自动更新，可查看更新记录后手动恢复。设置或任务记录无法可靠保存时停止自动执行，避免重复升级。
- 安装被移除或渠道发生变化时，旧设置保留为不可用状态，可在安装面板关闭，再为新安装重新开启。

当前只为后端能确认来源、位置和更新方式的安装提供开关。原生更新目前支持 macOS 上的 Claude 和 Grok；其他安装依实际检测能力显示原因。

自动更新期间，相应 Agent 的自动测活延后执行，不计为中转站故障。外部终端的进程检查发生在更新前；外部程序自行启动进程的行为不受 BalanceHub 控制。
