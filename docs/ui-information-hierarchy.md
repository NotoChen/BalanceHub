# 界面信息层级

适用于桌面 App 的资产、配置、账号、设置和操作详情。信息按用户当前要完成的事排序，避免把数据模型中的每个字段都变成一段副标题。

## 默认显示

- 当前对象、关键状态、必要的配置位置，以及当前可执行的操作。
- 填写字段必需的格式说明、示例和校验错误。MCP 表单继续帮助用户理解地址、命令、令牌和请求头的填写方式。
- 加载失败、解析异常、内容不完整、预览过期和已确认的差异。
- 确认修改前的 diff、删除范围、共同影响、生效方式和信任变化。

## 按需查看

来源证据、安装上下文、操作机制、一般使用说明和不可执行操作的详细原因，放入有明确名称的折叠入口。通用说明使用 `ContextDetails.vue`，统一间距、颜色及键盘焦点；有状态控制需求的文件 diff、影响范围和表单分组保留各自组件。

折叠内容不代表问题已解决，也不改变原生状态、能力判断或写入行为。可执行能力仍由 Rust 返回，前端按结果展示。

## 避免重复

- 标题下不再复述下方栏目清单；按钮旁不再用另一个标题重复按钮名称。
- 同一来源、状态和原因在同一层级只说一次。只有多个对象时才展示有区分价值的计数。
- 对象已经在窗口摘要中展示时，正文无需再重复同一条记录。
- 单一范围直接并入标题栏，不单独占一行解释；多个范围保留切换与跨范围选择提示。
- 不可执行操作提供原因查看入口；执行中和等待输入的操作保留原按钮及忙碌、禁用反馈。
- 编辑页面优先显示文件和编辑区，资源背景说明按需展开。

## 已对齐的界面

| 界面 | 信息组织 |
| --- | --- |
| 资产配置来源、Agent 使用浮层 | Agent、状态、位置和操作优先，来源和操作说明按需查看 |
| 原生资产详情 | 直接展示操作按钮，配置位置、关联安装和解析证据集中查看 |
| 资源正文、原生编辑和 MCP 表单 | 去除常驻教学式副标题，保留字段填写指导和错误 |
| 配置到 Agent | 范围与已选数量放在同一标题栏，修改和移除影响保留在预览中 |
| 同名资源比较 | 优先显示实际 diff，整理规则和操作限制按需查看 |
| 设置与中转站编辑 | 分区标题和实际设置项直接衔接 |
| 凭据与浏览器组件 | 当前状态及操作优先，一般说明按需查看 |
| CLI 启动预览 | 中转站仅展示一次，命令、目录及实际启动参数保留 |
| 请求日志详情 | 原始数据使用一个折叠入口，展开后可查看和复制 |

## 验证边界

前端构建和静态检查确认模板、类型与依赖关系。Agent 配置的实际桌面效果由用户验收，遵循仓库关于不执行自动测试、不写入合成配置和不进行桌面自动验收的约束。
